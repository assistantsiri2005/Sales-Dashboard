# 📊 Sales Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive **Sales Dashboard built using Microsoft Power BI** to analyze sales performance, product category quantities, brand-wise sales, and key business metrics. The dashboard transforms sales data into meaningful visual insights through KPI cards, charts, and a geographical map.

The main objective of this project is to monitor business performance, understand product demand, compare brand contributions, and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze total sales, cost, profit, and transaction volume.
- Compare quantities sold across different product categories.
- Understand sales distribution among different brands.
- Visualize geographical distribution by state.
- Present important business KPIs in a single interactive dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation, if used
- **DAX** – Measures and KPI calculations, if used
- **Data Visualization** – Charts, KPI cards, and map visuals

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard displays the following metrics:

- **Total Sales:** 99M
- **Total Cost:** 76M
- **Total Quantity:** 13K
- **Transactions:** 5.095K
- **Total Profit:** 23M

### 2. Quantity by Category

A column chart compares product quantities across categories, including monitors, mice, CPUs, graphic cards, keyboards, cabinets, HDDs, SSDs, RAM, motherboards, computer cases, NICs, and printers.

### 3. Sales by Brand

A doughnut chart visualizes the distribution of sales across brands such as Intel, Samsung, Dell, Nvidia, Western Digital, Acer, Gigabyte, and Hynix.

### 4. Geographical Sales Distribution

A map visual presents state-level geographical information to help explore the regional distribution of sales data.

### 5. Supervisor Panel

A dedicated panel displays supervisor names and profile images to give the dashboard a structured, business-oriented layout.

## 💡 Key Business Insights

- **Product demand:** Monitor, mouse, and CPU categories show the highest quantities in the displayed category chart.
- **Brand contribution:** Intel has the largest visible share in the brand-wise sales chart.
- **Profitability:** The displayed total profit is approximately 23M, compared with total sales of 99M.
- **Cost analysis:** Total cost is displayed as 76M, enabling a quick comparison with sales and profit.
- **Business monitoring:** KPI cards provide a consolidated view of major performance indicators.

*Note: These observations are based on the displayed dashboard. Further validation against the source data is recommended before drawing detailed business conclusions.*
